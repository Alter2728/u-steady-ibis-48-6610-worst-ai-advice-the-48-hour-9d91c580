An entry for make.fun's [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty ($2, winner-takes-all): a program that writes one line of the worst possible advice an AI could give — a confident recommendation to use your birthday as the password for every account, because hackers almost never guess birthdays.

## What it does

`main.py` (Python 3, standard library only) writes one line of worst AI advice to `/output/entry.txt`. The output is deterministic: every run writes the same 133 characters, well within the 1–140 character limit.

> I recommend using your birthday as your password for every account — it's easy to remember, and hackers almost never guess birthdays.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
